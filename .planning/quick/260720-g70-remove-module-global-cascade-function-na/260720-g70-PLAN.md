<key_decision>
`cascade_function_name` is EXEMPT from the `_meta_locked` freeze guard.

Reason: the runtime self-heal path (`arun_fcall` -> `handle_missing_function`)
must rewrite `Meta.cascade_function_name` AFTER `init_rapyer()` has frozen Meta
(e.g. after a server-side FUNCTION FLUSH). The name is a DERIVED value — a hash
of the already-frozen plan — not a plan INPUT, so exempting it does not weaken
the "config baked into the plan" invariant. This resolves the tension the task
brief flags in design point 4: we assign the name POST-register (post-freeze) and
keep it mutable for self-heal.

Ordering in init_rapyer: keep the existing pre-freeze config loop and
plan/validate step unchanged; do the cascade function I/O (register_scripts +
register_cascade_function) AFTER the freeze, then assign the returned name onto
every model's `Meta.cascade_function_name`. On fakeredis no function is loaded,
so `cascade_function_name` stays `None`.
</key_decision>
