<objective>
Pure refactor of the cascade planner: dissolve the now-nearly-empty CascadePlanner class into plain module functions, drop its dead field_attr/global_attr parameterization (the sole instantiation is CascadePlanner(), always with defaults; no _cascade_delete_fields/cascade_delete consumer exists anywhere to justify the parameterization), simplify the edge classifier to the single-hop static form actually used in production (the established/remaining_budget-decrement branches are dead in Python -- that runtime bookkeeping already lives exclusively in the Lua script), replace the raw-dict plan-table shape with frozen dataclasses (CascadeEdge, CascadePlanEntry), and clean up the one non-cycle-breaking in-function import plus stale comments left behind by prior cascade refactors. The Lua-injection boundary (_inject_cascade_plan) becomes models-only -- it accepts CascadePlanEntry/CascadeEdge dataclass entries exclusively (converted via dataclasses.asdict), with no plain-dict acceptance path, consistent with this project's standing preference for models over dicts; every test that previously hand-built plan dicts is rewritten to construct the dataclasses instead.
Purpose: Reduce rapyer/cascade/planner.py to its real shape now that traversal moved into Lua in Phase 2 -- a stateless static classifier feeding a typed plan table -- consistent with this project's standing preference for models over dicts and module-top imports except where a real circular-import boundary requires otherwise.
