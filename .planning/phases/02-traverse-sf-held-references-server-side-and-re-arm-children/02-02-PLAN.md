```python
async def aset_ttl(self, ttl: int, cascade: bool = False) -> Optional[CascadeResult]:
    ...
    if self.Meta.is_fake_redis or not self._contains_foreign_key():

        ...
        if not cascade:

        return CascadeResult(dangling_children=0, dangling_special=0)
    # cascade is a per-call flag: 0 = root's own keys only, 1 = walk the graph.
    scripts_registry.run_fcall(pipe, self.Meta.cascade_function_name, 1, self.key,
                                type(self).__name__, SPECIAL_FIELD_KEY_PREFIX, ttl,
                                1 if cascade else 0)
    ...
```
`self.Meta.is_fake_redis or not self._contains_foreign_key()`: the `is_fake_redis` check is the FIRST operand of an `or`, so on fakeredis this branch is always taken regardless of `_contains_foreign_key()`'s value — a companion plan (02-04) changes what `_contains_foreign_key()` returns for SF-only parents, but that change is unreachable on fakeredis. Nothing in this plan's assertions depends on `_contains_foreign_key()`'s return value.

`all_keys` (`rapyer/base.py:643-658`) includes every special-field key via `_all_keys_for_key`, so a fakeredis-fallback EXPIRE on the root refreshes the SF container's own key alongside the main key.
