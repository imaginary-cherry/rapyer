<objective>
Teach the static cascade planner to recognize `ForeignKey` references held inside special-field containers — `RedisSet[Reference[T]]` and `RedisPriorityQueue[Reference[T]]` — and emit them into the per-class cascade plan table as a distinct SF-held-ref edge shape (SF key suffix + target class + container kind + depth). Pure annotation introspection; ZERO Redis I/O.

Purpose: Close the classification gap so the Phase-2 server-side traversal has the exact data it needs to read SET (`SMEMBERS`) / ZSET (`ZRANGE`) members and follow the refs. Today these fields land only in `_special_field_names` (their own key gets EXPIRE'd via a refresh-only special-suffix) but emit no cascade edge, so the FK strings inside the set/zset are never followed.

Output: `CascadeEdge` gains an `sf_container` discriminator; `build_cascade_plan` gains a dedicated SF discovery pass; new test fixtures + unit tests prove the edge shape, precedence, hash stability, and fail-fast validation.

Implements CASF-01, CASF-02, CASF-03 and ROADMAP Phase-1 success criteria 1-4.

Design contract is LOCKED in 01-CONTEXT.md (D-01..D-04). Do not reopen those decisions — implement them.
</objective>
